About

Data got interesting to me when I stopped treating it as a numbers problem.

A business bleeds revenue for a reason. Systems fail at 2am for a reason. Customers leave quietly, and there's usually a pattern if you actually go looking. I started with curiosity and a lot of broken Python scripts. Then I got a real internship at Howden Insurance Brokers and stopped learning data in theory—and started doing it.

Automated 25+ daily reports, cut manual work by 75% using Python and VBA, built Power BI dashboards that teams actually opened. What I took away from that: an insight that doesn't reach the right person, reliably, might as well not exist.

That's why I don't stop at the dashboard. I've built pipelines, ML models, FastAPI backends, Docker containers, CI/CD workflows—churn prediction systems, traffic control models, asset monitoring dashboards—all with real business logic inside them.

I've also done AIESEC leadership and a volunteer exchange in Sri Lanka, which sounds like resume filler but genuinely taught me that working with data and working with people are harder to separate than the job description usually admits.
