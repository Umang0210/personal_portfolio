# Umang Garg — Personal Portfolio

A monochrome, single-page portfolio website showcasing my profile as a **Data Analyst & Engineer**. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies.

## 🔗 Live Preview

Open `index.html` in your browser, or serve locally:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`

## 📂 Project Structure

```
personal-portfolio/
├── index.html      # Single-page HTML with 8 sections
├── styles.css      # Monochrome design system & responsive layout
├── script.js       # Animations, counters, typing effect, mobile menu
├── README.md
└── RESUME/
    ├── UMANG_GARG_CV.pdf
    └── Profile.pdf
```

## ✨ Features

- **Monochrome Design** — Strict black/white/grey palette with a corporate aesthetic
- **Typing Effect** — Rotating taglines in the hero section
- **Animated Counters** — Key metrics count up on scroll with cubic easing
- **Scroll Animations** — Fade-up transitions via Intersection Observer
- **Mobile Responsive** — Hamburger menu and adaptive layouts for all screen sizes
- **Active Nav Tracking** — Navigation highlights the current section on scroll
