# Umang Garg — Personal Portfolio

A monochrome, single-page portfolio website showcasing my profile as a **Data Analyst & Cloud Engineer**. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies.

## 🔗 Live Preview

Open `index.html` in your browser, or serve locally:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`

## ✨ Features

- **Monochrome Design** — Strict black/white/grey palette with numbered monochrome icons
- **Typing Effect** — Rotating taglines in the hero section
- **Animated Counters** — Key metrics count up on scroll with cubic easing
- **Scroll Animations** — Fade-up transitions via Intersection Observer
- **Mobile Responsive** — Hamburger menu and adaptive layouts for all screen sizes
- **Active Nav Tracking** — Navigation highlights the current section on scroll
