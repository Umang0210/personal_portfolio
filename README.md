# Personal Portfolio Website

A responsive single-page personal portfolio website showcasing my background, skills, professional experience, and data analytics projects. This portfolio is built to present my work as a **Data Analyst focused on automation, analytics, and workflow optimization**.

---

## Overview

This project serves as my primary online professional profile. It consolidates my academic background, industry experience, and hands-on projects into a single, structured, and accessible platform.

The portfolio emphasizes:
- Data analytics and automation capabilities
- Real project work with business context
- Clean UI with clear information hierarchy
- Practical tooling used in analytics and reporting roles

## Running the Project Locally

### Option 1: Open Directly
Open `index.html` in a browser.

### Option 2: Run Using Python (Recommended)

```
python run_server.py
```

Then open:
```
http://localhost:8000
```

---

## Deployment

This project can be deployed using GitHub Pages:
1. Push the repository to GitHub
2. Go to Repository Settings → Pages
3. Select branch `main` and folder `/root`
4. Save and wait for deployment
